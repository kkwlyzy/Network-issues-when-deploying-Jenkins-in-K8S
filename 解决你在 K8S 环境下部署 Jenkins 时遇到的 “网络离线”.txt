这份文档旨在解决你在 K8S 环境下部署 Jenkins 时遇到的 “网络离线”、“插件安装失败” 以及 “证书签名过期” 的连锁问题。

Jenkins 在 K8S 环境下的网络与插件修复指南
1. 问题根源分析
网络误判：Jenkins 默认连接 google.com 检测联网状态，国内环境会直接报 "Offline"。

版本冲突：老版本 Jenkins 镜像（如 v2.60）无法加载新版插件（要求 v2.130+）。

签名过期（核心问题）：报错显示 NotAfter: 2026-02-21。这意味着 Jenkins 的安全机制发现镜像站（华为/清华）的数字签名已过期，从而拦截了所有插件下载请求。

2. 核心解决方案：三步修复法
第一步：修改 Deployment 禁用签名校验
这是解决 2026年证书过期 报错的唯一手段。通过 Java 参数强制 Jenkins 跳过签名检查。

在 Master 节点执行：

Bash
kubectl set env deployment/jenkins -n jenkins-k8s JAVA_OPTS="-Dhudson.model.DownloadService.noSignatureCheck=true"
注意：只要你的 Deployment 挂载了 PVC 磁盘（/var/jenkins_home），此操作会导致 Pod 滚动重启，但配置和数据不会丢失。

第二步：强制更换国内镜像源（无需 vi）
由于容器内通常没有 vi/vim，直接使用 sed 命令在 Pod 运行时修改配置文件。

Bash
# 1. 获取当前运行的 Pod 名称并修改主配置
POD_NAME=$(kubectl get pod -n jenkins-k8s -l app=jenkins -o jsonpath='{.items[0].metadata.name}')

# 2. 将官方更新源替换为清华大学镜像源
kubectl exec -it $POD_NAME -n jenkins-k8s -- sed -i 's|https://updates.jenkins.io/update-center.json|https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json|g' /var/jenkins_home/hudson.model.UpdateCenter.xml
第三步：手动初始化插件元数据（解决下载 404）
Jenkins 在下载插件时仍会尝试访问官方地址，需要手动下载并替换 default.json 中的下载链接。

Bash
kubectl exec -it $POD_NAME -n jenkins-k8s -- bash -c "
mkdir -p /var/jenkins_home/updates && \
curl -L https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json > /var/jenkins_home/updates/default.json && \
sed -i 's|https://updates.jenkins.io/download|https://mirrors.tuna.tsinghua.edu.cn/jenkins|g' /var/jenkins_home/updates/default.json && \
sed -i 's|http://www.google.com|https://www.baidu.com|g' /var/jenkins_home/updates/default.json"
3. 浏览器端最终操作
访问 Jenkins 界面：如果仍卡在插件安装页，点击 "Skip Plugin Installations" 直接进入主页。

强制刷新：进入 Manage Jenkins -> Plugins -> Advanced settings。

检查站点：确认页面最下方的 Update Site 为：
https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json

生效：点击 Submit，然后点击右下角的 Check now。

安装：此时回到 Available plugins 搜索 Localization: Chinese 或 Git 即可正常安装。

4. 进阶建议（持久化与版本）
检查存储：执行 kubectl get pvc -n jenkins-k8s。如果没有 Bound 状态的 PVC，建议在重启前先用 kubectl cp 备份 /var/jenkins_home。

镜像版本：建议使用 jenkins/jenkins:2.440.3-lts-jdk17 或更高版本，以获得最佳的插件兼容性。
